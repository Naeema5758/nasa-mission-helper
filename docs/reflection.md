# Reflection
Before this lab i had never used github ever so most of the concepts were completely new to me
Through completing the lab step by step i learned how a repository is used to keep project files in one place and how issues can be used to divide a project into smaller and clearer tasks.
I also learned that commits are useful for recording changes as the project develops and moves on
In addition, i understood the purpose of branches which allow changes to be made separate from the main branch, and pull requests which are used to review/merge those changes back into the main project
This helped me see how GitHub can be useful for organizing/tracking the progress of a project
The most challenging part for me was understanding the relationship between branches, commits, and pull requests because I had no previous experience with them.
Another was making sure i was working on the correct branch before making each commit because at first I was worried that I might accidentally save changes directly to the main branch.
I also had to pay close attention when creating pull requests to make sure I was merging the correct feature branch into main.
However once I created the branches, made the commits and completed the pull requests myself, the process became much easier to understand.
I enjoyed creating the issues because they gave the project a clear structure and made each task easy to follow
I also enjoyed seeing how the project changed step by step through commits because it made my progress feel organized
If I had more time and more experience with GitHub I would develop the NASA Mission Helper into a more practical mission-planning tool. 
For example I would add separate preparation stages such as equipment checks, communication checks, safety checks, and launch readiness, with a way to mark each task as completed and track overall progress
